# Product Images - WINKY STORE

## Lokasi Folder

```
public/images/products/
```

## Cara Menambah Gambar

1. Cari gambar produk di Google Images
2. Download gambarnya
3. Rename sesuai nama file di bawah ini
4. Masukkan ke folder `public/images/products/`

|------|------------|
| `no-image.png` | Gambar default jika produk belum ada foto (sudah ada) |

## Tips

- Gunakan format `.jpg` atau `.png`
- Ukuran ideal: 800x600 px atau lebih besar
- Gambar akan ditampilkan dengan `object-fit: contain` (proporsi terjaga)
- Jika file tidak ditemukan, otomatis tampilkan `no-image.png`
